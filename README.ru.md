# Look Out the Window

[English](README.md) · [Русский](README.ru.md)

Статичная лендинг-страница «Посмотри в окно» на HTML, CSS и JavaScript.

## Начало работы

Откройте `index.html` в браузере.

## Структура проекта

- `index.html` — разметка страницы
- `styles/` — стили
- `scripts/` — скрипты
- `fonts/`, `images/` — ресурсы
